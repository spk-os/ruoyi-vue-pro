# model_4 模块文档

## 概述

model_4 模块是 Yudao AI 模块的一部分，负责管理 AI 相关的核心实体和业务逻辑。该模块提供了 API 密钥、AI 模型、AI 工具和 AI 聊天角色的完整生命周期管理功能，包括创建、读取、更新、删除（CRUD）操作，以及与外部 AI 服务的集成。

## 架构概述

model_4 模块遵循典型的分层架构设计，主要包含服务层实现。以下是该模块的主要组件及其关系：

```
[API 密钥服务] --> [服务层]
[AI 模型服务] --> [服务层]
[AI 工具服务] --> [服务层]
[AI 聊天角色服务] --> [服务层]
[服务层] --> [数据访问层]
[服务层] --> [外部 AI 服务集成]
[数据访问层] --> [(数据库)]
[外部 AI 服务集成] --> [Spring AI 框架]
[外部 AI 服务集成] --> [Midjourney API]
[外部 AI 服务集成] --> [Suno API]
[外部 AI 服务集成] --> [通义千问 API]
[外部 AI 服务集成] --> [Ollama API]
```

### 子模块

model_4 模块可以进一步分割为以下子模块：

1. [API 密钥管理](model_4_apikey.md)：负责 AI API 密钥的存储、验证和管理
2. [AI 模型管理](model_4_model.md)：负责 AI 模型的配置、管理及与 Spring AI 框架的集成
3. [AI 工具管理](model_4_tool.md)：负责 AI 工具的注册、管理和调用
4. [AI 聊天角色管理](model_4_chatrole.md)：负责 AI 聊天角色的创建、管理及其关联的知识库和工具

## 功能说明

### API 密钥管理
提供 AI API 密钥的完整 CRUD 操作，包括：
- 创建新的 API 密钥
- 更新现有 API 密钥信息
- 删除 API 密钥
- 查询单个或多个 API 密钥
- 分页查询 API 密钥列表
- 验证 API 密钥的有效性和状态

### AI 模型管理
提供 AI 模型的配置和管理功能，包括：
- 创建、更新、删除 AI 模型配置
- 查询 AI 模型信息
- 分页查询 AI 模型列表
- 验证 AI 模型的可用状态
- 与 Spring AI 框架集成，获取聊天模型、图像模型等具体实现
- 支持多种 AI 平台（通义千问、Ollama、Midjourney、Suno 等）

### AI 工具管理
提供 AI 工具的注册和管理功能，包括：
- 创建、更新、删除 AI 工具
- 查询 AI 工具信息
- 分页查询 AI 工具列表
- 验证工具名称是否存在
- 根据状态查询工具列表

### AI 聊天角色管理
提供 AI 聊天角色的完整管理功能，包括：
- 创建、更新、删除 AI 聊天角色
- 查询 AI 聊天角色信息
- 分页查询 AI 聊天角色列表
- 验证聊天角色的有效状态
- 管理聊天角色关联的知识库和工具
- 支持个人聊天角色（仅特定用户可见）和公共聊天角色

## 与其他模块的关系

model_4 模块主要依赖于：
- 数据访问层（DAO）：与 MyBatis Mapper 交互进行数据持久化
- 其他 AI 模块服务：如知识库服务（用于聊天角色关联的知识库验证）
- 框架工具类：如 BeanUtils、ServiceExceptionUtil 等通用工具
- 外部 AI 服务：通过 Spring AI 框架集成各种 AI 平台 API

该模块为上层的控制器层（Controller）提供服务，为前端界面和 API 接口提供后端业务逻辑支持。

## 数据模型

model_4 模块主要操作以下数据对象：
- AiApiKeyDO：API 密钥数据对象
- AiModelDO：AI 模型数据对象
- AiToolDO：AI 工具数据对象
- AiChatRoleDO：AI 聊天角色数据对象

这些数据对象定义在对应的 DAL（Data Access Layer（Data Access Layer）的MyBatis映射文件中。
