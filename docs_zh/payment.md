# 支付模块

## 概述

支付模块负责处理 ERP 系统中的付款交易。它提供创建、更新、查询和处理供应商付款的功能。

## 架构

支付模块结构如下：

- [付款分页请求 DTO](payment_page_req.md)
- [付款响应 DTO](payment_resp.md)
- [付款保存请求 DTO](payment_save_req.md)

每个子模块的详细信息请参考其 respective 文档文件。

## 详情

有关每个子模块的详细信息，请参考上面链接的文档文件。

注意：支付模块主要由支付控制器使用的 DTO（数据传输对象）组成。实际的业务逻辑位于服务和数据访问层，由于这些不属于提供的核心组件，因此不在此文档中涵盖。
