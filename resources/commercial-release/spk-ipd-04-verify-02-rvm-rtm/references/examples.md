# ACT-03-05-02 可复演案例

案例用于选择执行分支，不是可复制到交付物的答案；复演时替换成真实项目、基线、工具输出和证据。

## 案例 1：正常完成

输入齐全且哈希一致。Agent 从“读取 PRS、架构质量场景、风险和验证基线”执行到“形成双向可查询且版本锁定的 RVM_RTM_Baseline”，填写 `RVM_RTM_Baseline`，运行确定性校验并提交 Claim/Evidence 索引。验证器返回 0 且下游确认可消费后标记 COMPLETE。

## 案例 2：关键输入缺失

执行“为每项需求分配唯一验证对象和可判定验收准则”时发现数据无授权或上游 Artifact 缺版本。Agent 不生成推测内容，将状态置为 BLOCKED，提交缺失项、影响、检查位置、所需 owner 和恢复后的重跑起点。

## 案例 3：证据冲突

两个可信来源对 `建立 RVM/RTM` 的关键结论相反。Agent 保留双方证据，检查口径、时间、样本和版本，输出分情景结论并降低置信度；影响门禁时触发独立验证，不做多数投票。

## 案例 4：工具失败与恢复

真实工具在“映射 requirement 到 verification method 到 test case 到 evidence”阶段超时或只返回部分结果。Agent 保存请求和错误，检查分页与限流后按预算重试；仍失败则从最后有效快照恢复、标记未覆盖范围并升级，不把部分结果称为全量。

## 案例 5：边界、复核与移交

产物已生成，但“形成双向可查询且版本锁定的 RVM_RTM_Baseline”验收未通过或活动要求人工/独立决策。Agent 保持 IN_PROGRESS/BLOCKED，提交验证回执；授权真实落盘且条件关闭后，重新计算哈希并移交。
